# Frozen Food App
### Nama: Yuri
### Kelas: 11 rpl

## Cara menjalankan aplikasi:
- Import database.sql terlebih dahulu ke mysql.
- Create folder "frozen_food" di htdocs
- buka localhost/htdocs/frozen_food

## Fitur Aplikasi
- Menambahkan produk, kategori, dan supplier baru.
- Mengedit dan menghapus data produk, kategori, atau supplier.
- Mencari data produk dengan memfilter atau mencari dengan salah satu data nama, kategori, produk, atau jumlah stok.
